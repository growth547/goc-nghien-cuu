# Danh sách thang đo chờ bổ sung

Tác vụ tự động mỗi ngày lấy từ đầu danh sách (sau các đề xuất trên GitHub issue có nhãn `de-xuat-thang-do`), làm theo `docs/SCALES_BRIEF.md`, rồi chuyển dòng đã xử lý xuống mục "Đã xử lý" kèm kết quả.

Mỗi dòng: `slug | thang đo, tác giả (năm) | ghi chú`.

## Chờ làm
