1. Tải file câu trả lời
File tải từ Google Forms (Câu trả lời → Tải xuống CSV, hoặc trang tính liên kết → Tải xuống .xlsx), Microsoft Forms (Mở trong Excel) hoặc Genius Data (Xuất CSV). File được đọc ngay trong trình duyệt, không gửi lên máy chủ nào.
2. Đặt mã biến cho từng cột Mã được đọc từ tiêu đề cột kiểu “TT1. Giới tính” hoặc “Mức độ đồng ý [PU1. …]”. Cột không có mã được đặt tạm Q + số cột; sửa thành mã của bạn, hoặc dán bảng mã hoá bên dưới để công cụ tự khớp theo nội dung câu hỏi.
Dán hoặc tải bảng mã hoá (không bắt buộc)
Nhãn chữ (Hoàn toàn không đồng ý … Hoàn toàn đồng ý; Rất không hài lòng … Rất hài lòng; Strongly disagree … Strongly agree) được đổi sang số. Ô đã là số (“4” hoặc “4 - Đồng ý”) giữ nguyên số.
Dùng để đảo điểm: điểm mới = thấp nhất + cao nhất − điểm cũ. Giá trị ngoài khoảng này bị coi là thiếu và được báo.

Mở trong SPSS: đặt file CSV và file .sps cùng một thư mục, mở file .sps (File → Open → Syntax), sửa đường dẫn ở dòng CD rồi chọn Run → All. SPSS đọc dữ liệu kèm nhãn biến, nhãn giá trị và mã thiếu.

Phân tích tiếp: công cụ Phân tích dữ liệu chưa nhận dữ liệu chuyển thẳng từ trang này. Tải “File sạch (CSV)” rồi tải file đó lên trang phân tích. Câu đảo chiều trong file sạch đã được đảo điểm, nên đừng khai báo lại ở ô “Câu đảo chiều” bên đó.
